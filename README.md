# Evoc Labs CRM

A professional CRM system for managing leads, tracking pipeline progress, and team collaboration.

## Tech Stack

- **Frontend**: React 19 + TypeScript + Vite
- **Styling**: Tailwind CSS
- **Icons**: Lucide React
- **Authentication**: Firebase Auth
- **Database**: Firebase Firestore

## Domain

The application is hosted at [crm.evoclabs.com](https://crm.evoclabs.com).
